# breakoutmusic.io

Сайт Breakout (музичний промо-сервіс) + бекенд. Хостинг: Cloudflare Pages + Workers.

## ⚠️ Структура — що редагувати, а що ні

| Папка / файли | Що це | Можна редагувати? |
|---|---|---|
| **`live-snapshot/`** | ✅ **РОБОЧИЙ САЙТ** — саме ця папка деплоїться на breakoutmusic.io | **ТАК — тільки тут** |
| `breakout-api/` | Бекенд (Cloudflare Worker): платежі, замовлення, промокоди, адмінка | Тільки за погодженням з Яною |
| `*.html`, `*.js`, `*.css` в корені | ❌ Застаріла копія сайту (червень 2026), лишилась для історії | **НІ — зміни сюди не потраплять на сайт** |
| `website-upload/` | ❌ Теж застаріла копія | **НІ** |

## Процес роботи

1. Перед початком: `git pull origin main`
2. Створи свою гілку: `git checkout -b назва-задачі`
3. Зміни вноси **тільки в `live-snapshot/`**
4. Закоміть і запуш гілку, відкрий **Pull Request** у `main`
5. **Деплой робить Яна** після мержа — пуш у GitHub сам по собі сайт НЕ оновлює

## Технічні нюанси

- **Кеш:** сторінки кешуються до 1 години, `assets/*` — на рік. Якщо міняєш JS/CSS — онови версію в підключенні (`?v=...`), якщо міняєш файл в `assets/` — залий під новим імʼям.
- **Ніяких секретів у код:** API-ключі живуть у секретах Cloudflare Worker, у репозиторії їх бути не може.
- **Платежі (HiPay, Cardinity, PayPal), промокоди, замовлення** — це все `breakout-api/` + база D1. Не чіпати без погодження.
- Деплой (для довідки, робить Яна): сайт — `npx wrangler pages deploy live-snapshot --project-name=breakout-music-io --branch=main`, бекенд — `npx wrangler deploy` з папки `breakout-api/`.
